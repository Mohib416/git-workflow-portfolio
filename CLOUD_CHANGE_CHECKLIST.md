# Cloud Change Management Checklist

This checklist describes the main steps for managing a cloud infrastructure change.

## 1. Pre-Change Checks
- [ ] Review the change request.
- [ ] Identify affected cloud resources.
- [ ] Review the proposed configuration changes.
- [ ] Confirm approval before implementation.
- [ ] Prepare a rollback plan.

## 2. Implementation
- [ ] Apply the approved configuration changes.
- [ ] Follow the planned implementation procedure.
- [ ] Document the changes performed.

## 3. Post-Change Verification
- [ ] Verify that the affected resources are operational.
- [ ] Check system health and application availability.
- [ ] Review relevant logs and monitoring information.
- [ ] Confirm that the change was successful.
- [ ] Document the final result.

## 4. Version Control and Review
- [ ] Create a feature branch for new changes.
- [ ] Review changes before committing.
- [ ] Use clear and descriptive commit messages.
- [ ] Review the changes before merging into main.
- [ ] Verify the repository status after merging.
